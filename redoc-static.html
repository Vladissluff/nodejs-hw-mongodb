Contacts

Operations for contacts data.

Get all contacts

Get all contacts

Authorizations:
bearerAuth
query Parameters
page
integer
Example: page=1
perPage
integer
Example: perPage=10
sortBy
string
Enum: "name" "phoneNumber" "email" "isFavourite" "contactType" "createdAt" "updatedAt"
Example: sortBy=name

You can specify all contact fields. Default sort by "_id"

sortOrder
string
Enum: "asc" "desc"
Example: sortOrder=desc

You can sort in descending order. Default is ascending.

type
string
Enum: "work" "home" "personal"
Example: type=work

You can filter contacts by type

isFavourite
string
Enum: "true" "1" "false" "0"
Example: isFavourite=true

You can show favourite contacts only. Or exclude them

Responses

http://localhost:3000/contacts
https://contacts-book-7tj4.onrender.com/contacts
